# 数据目录说明

原始录音、标注片段与模型权重**体积较大，不纳入 Git**。请把数据放到本目录，
或通过环境变量 `FISH_DATA_ROOT` / `FISH_MODEL_DIR` / `FISH_REC_DIR` 指向实际位置。

## 训练集结构（dataset_train_v1）

```
dataset_train_v1/
├── fish/            # 真鱼：成组双/三脉冲"咕咕声"（32）
├── stress/          # 应激：密集杂乱扑腾（37）
├── water/           # 水流/设备：均匀节拍、宽频低轰鸣（48）
├── impact/          # 撞击：孤立宽频"咚"（45）
├── _待复核标签/      # 存疑样本，不参与训练
├── _隔离剔除/        # 明确剔除
└── 数据划分_manifest.csv
```

`数据划分_manifest.csv` 列：`文件名,类别,类别id,源段,split,来源`

- 类别 id：`fish=0, stress=1, water=2, impact=3`
- `split`：按**源录音段**分组划分 train/val（同一源段不跨训练/验证，防止数据泄漏）
- 本版本共 162 个片段：train 122 / val 40

## 长录音

成鱼全天数据为 48 个 30 分钟 wav（96 kHz / 24 bit），文件名形如：

```
#30054#[020]@20250313_185156@MID@96Ksps.wav
#              └─ 时间戳 YYYYMMDD_HHMMSS，解析用于昼夜曲线横轴
```

## 真鱼判据（人工标注金标准）

- 成组双/三脉冲，组内间隔 40–100 ms，组间规律长停顿（约 360–420 ms）
- 峰频约 688–900 Hz，窄带，低频底噪干净
- 孤立宽频"咚" → 撞击；连续密集杂乱扑腾 → 应激；均匀节拍+宽频+低轰鸣 → 水流/设备
